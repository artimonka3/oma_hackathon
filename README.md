# ОМА от первой идеи до готового ремонта

ОМА.Собери помогает определить решение, примерить его и подготовить покупку. ОМА.Прораб связывает проверку комплекта с организацией работ и сопровождением до приёмки заказчиком. Оба сервиса используют один проект ремонта.

Проект находится на этапе спецификации. Серверная реализация планируется на Go, интеграции магазина — через API с отдельным демонстрационным симулятором.

## Основные документы

- [Продуктовая спецификация](OMA-product-spec.md) — согласованные решения, общий путь, отдельное описание каждого сервиса, связь с магазином, бизнес-модель и демонстрация.
- [Техническое приложение](docs/technical-spec.md) — архитектура Go, данные, состояния, проектируемые API, оформление заказа, этапы реализации и критерии проверки.

## Материалы брейншторма
