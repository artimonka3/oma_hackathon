# Рабочий интерфейс

`index.html`, `app.js`, `styles.css`, `assets/` встраиваются в Go-бинарник.
После изменений пересоберите app: `docker compose up --build -d --wait`.
Разработка без сборщика JS; Node нужен только для форматирования.

Основные маршруты: #welcome, #leftovers, #room, #ar, #variants, #cart,
#prorab, #review, #checkout, #delivery, #plan, #tracking, #report, #foreman, #projects.

Карточки остатков поддерживают поиск, категории, несколько позиций и явное подтверждение.
Состояние редактируемого черновика хранится в sessionStorage, проект и решения — на сервере.
Сервер — источник сумм, количества, версий и разрешений; браузер только отображает результат.

AR получает URL через /api/v1/config. AR — только просмотрщик расстановки мебели, не замеры и не подсказки.
Пустой URL показывает ожидание подключения. Точка интеграции описана в ../docs/AR.md.
AI demo/live также определяется сервером, секретов в JS нет.

Полный запуск, PostgreSQL, AIHubMix и ограничения: ../README.md.

Основной запуск: `docker compose up -d --build` из корня. Витрина вашего магазина доступна на `/shop/`; материалы и фото загружаются из его API. AR-кнопка запускает AR Config на Android по intent-ссылке. Портреты демо-прорабов — локальный `assets/foremen-atlas-v1.png`; описание в `docs/ASSETS.md`.
