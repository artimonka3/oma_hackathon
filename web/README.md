# Браузерный слой

Каталог зарезервирован под страницы и браузерные компоненты общего кабинета:
конструктор, магазин, кабинеты ролей, AR-примерка (раздел 1.1 технической
спецификации). На текущем этапе каркаса браузерного кода нет; серверная часть
уже отдаёт JSON API, к которому подключается будущий фронтенд.
