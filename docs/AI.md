# AI: GLM через AIHubMix

`ai.Provider` имеет один метод `PrepareVariants(ctx, PrepareRequest) (Draft, error)`.
Реализации: `StubProvider` для demo и `ChatProvider` для live. Сервис Подбор ставит задание,
worker внутри app вызывает провайдер, результат проходит серверную валидацию.

## Конфигурация

| Переменная | По умолчанию | Назначение |
|---|---|---|
| AI_MODE | demo | demo/live; live без ключа останавливает запуск |
| AI_API_KEY | пусто | ключ AIHubMix, только сервер |
| AI_BASE_URL | https://aihubmix.com/v1 | база Chat Completions, без `/chat/completions` |
| AI_MODEL | glm-5.3-flash | точный ID маршрута модели |
| AI_TIMEOUT | 60s | 1–120 секунд |
| AI_MAX_TOKENS | 4096 | 512–8192, включая выход модели по правилам провайдера |

Для GLM не передаём `thinking.type=disabled`: семейство 5.3 не позволяет отключить thinking.
Используем `reasoning_effort=low`. Увеличивайте лимит, если модель возвращает `finish_reason=length`;
расход на reasoning зависит от провайдера. Актуальный тариф и доступ проверяются в кабинете AIHubMix.

## Что передаётся

Описание задачи, названия/размеры комнат и подтверждённые остатки, список допустимых SKU и компактные данные каталога
(название, тип, единица, упаковка, цена). Только основной материал paint/flooring/tiling,
положительный складской остаток, достаточный для геометрии с учётом подтверждённых остатков. В Compose источник — API клона с 611 товарами; модель получает до 24 подходящих позиций. Категории с неизвестными единицами и неподходящие покрытия исключаются. Масса краски сохраняется в кг, цена за м² не считается ценой за упаковку. Изображения, фотоотчёты и токены участников автоматически не отправляются.

Модель возвращает варианты: `id`, `title`, `summary`, `skus`; отдельно — `questions`.
Каждый вариант содержит один основной материал из разрешённого каталога. Программа проверяет
структуру, SKU, уникальность ID, длины и число вариантов. Поля mode/model задаёт провайдер приложения,
а не ответ нейросети. Количество, округление упаковок, цены заказа и разрешения определяет Go.

## Стоимость и сбои

Один запрос на нажатие подбора; автоматических повторов по 429/таймауту нет, чтобы не скрывать расходы.
Фоновые задания после аварийного перезапуска могут выполняться повторно. Ограничьте бюджет ключа
в AIHubMix. История диалога и фотографии не раздувают контекст.

Ошибки HTTP upstream показываются кодом и безопасным текстом. Тело ошибки провайдера,
ключ и Authorization в логи не выводятся. Некорректный JSON или неизвестный SKU не меняет
подтверждённый комплект. Live не маскируется как demo при сбое; для demo смените конфигурацию явно.

## Проверки

`go test ./internal/ai` запускает mock HTTP upstream, проверяет авторизацию/endpoint,
лимиты, валидный ответ, неизвестный SKU, пустой JSON, неправильный JSON, 401,
отсутствие ключа и отсутствие автоматического повтора.

28 октября 2026 выполнен один успешный живой подбор GLM-5.3-Flash через AIHubMix.
При смене ключа или маршрута доступ проверяйте заново.
Добавьте ключ в `.env`, включите live, пересоздайте app и выполните один подбор через интерфейс.
Варианты должны получить `mode=live`; это поле также сохраняется в PostgreSQL.
