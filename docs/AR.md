# AR: внешний просмотр мебели на Android

AR Config — отдельное Android-приложение для расстановки мебели. На сайте используется обычная ссылка:

```html
<a href="intent://#Intent;scheme=arconfig;package=com.spatial.arconfig;end">Открыть AR просмотр</a>
```

Кнопка запуска появляется только при Android User-Agent. Приложение `com.spatial.arconfig`
должно быть установлено. Браузер передаёт запуск операционной системе; работу самого приложения
проверяют на Android-устройстве. На компьютере и iOS экран AR объясняет, что нужен Android,
и предлагает вернуться к подбору. Встроенного iframe и переменной `AR_VIEWER_URL` больше нет.

Инструмент только размещает мебель. Размеры комнаты для расчёта материалов пользователь вводит
вручную. Сайт не получает из AR результаты измерений, подсказки или данные камеры.
