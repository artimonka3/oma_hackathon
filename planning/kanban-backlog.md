# Задачи команды ОМА

Дата подготовки: 27 октября 2026 года. 91 исполняемых задач: 83 MVP и 8 Next, в 13 блоках. Это полный бэклог выбранной спецификации, а не обещание реализовать всё за один хакатон. Для демонстрации используется один сквозной маршрут с небольшим количеством данных.

Конкретные исполнители, даты и длительности командой ещё не заданы. Роли указаны для назначения; размер M — предварительный ориентир работы до 1–2 дней специалиста, S — меньший объём. Это не расписание и не сумма трудозатрат. Все задачи пока не выполнены.

Источники: [согласованный продукт](../docs/OMA-product-spec.md), [техническая спецификация](../docs/technical-spec.md). Идентификаторы F01 и подобные — локальные ID планирования, а не номера GitHub Issues.

## С чего начать

- [F01](#f01) — Создать каркас Go-приложения и доменные модули. Роль: Backend Go.
- [F02](#f02) — Зафиксировать OpenAPI и общие DTO основных сценариев. Роль: Tech Lead.
- [F03](#f03) — Подготовить локальное окружение PostgreSQL и миграции. Роль: DevOps.
- [F04](#f04) — Подготовить макеты полного пути и общий UI-набор. Роль: Product/UX.
- [V01](#v01) — Проверить AR-устройство и выбрать путь захвата помещений. Роль: 3D/AR.

Следующие задачи становятся готовы после завершения их блокеров. Не нужно заканчивать целый блок, чтобы начать независимую работу другого.
